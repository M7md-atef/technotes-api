# techNotes User Stories

User stories describe the outcome a person needs, rather than prescribing a particular implementation. Status reflects the current delivery checklist.

## Product and access

- [x] **As a business owner, I want techNotes to replace the existing sticky-note process, so that service work is recorded and managed in one place.**
- [x] **As a prospective user, I want to see a public page with basic contact information, so that I can learn how to reach the business before signing in.**
- [x] **As an employee, I want to sign in to techNotes, so that I can securely access the notes and tools available to me.**
- [x] **As a signed-in user, I want to see a welcome page, so that I can orient myself and choose where to go next.**
- [x] **As a signed-in user, I want clear, consistent navigation, so that I can quickly reach the pages available to me.**
- [x] **As a user, I want to switch between light and dark mode and keep my preference after reload, so that the interface remains comfortable for me to use.**
- [x] **As a signed-in user, I want to see my account name and role, so that I know which account and permissions are active.**
- [x] **As a signed-in user, I want to log out, so that I can end my session when I finish using the app.**
- [x] **As an employee, I want to sign in again at least once every seven days, so that access is periodically revalidated.**
- [x] **As an administrator, I want to deactivate an employee account, so that I can promptly revoke that employee’s access when needed.**

## Service notes

- [x] **As an employee, I want each service note assigned to a specific employee, so that responsibility for follow-up is clear.**
- [x] **As an employee, I want a note to include a ticket number, title, body, and created and updated dates, so that I can identify the service task and understand its history.**
- [x] **As an employee, I want notes to have an open or completed status, so that I can track which service tasks still need work.**
- [x] **As a customer checking in, I want a service note to be created for my visit, so that the work needed for my service can be recorded.**
- [x] **As an employee, I want to view and edit only the notes assigned to me, so that I can manage my work without changing another employee’s notes.**
- [x] **As a manager or administrator, I want to view and edit any service note, so that I can oversee work and help resolve issues across the team.**
- [x] **As a manager or administrator, I want to delete service notes, so that I can remove records when they should no longer be retained.**

## Users, roles, and responsive access

- [x] **As an administrator, I want users to have an employee, manager, or administrator role, so that access can be managed according to each person’s responsibilities.**
- [x] **As a manager or administrator, I want to access user settings, so that I can manage team accounts.**
- [x] **As a manager or administrator, I want to create user accounts, so that new team members can be given access to techNotes.**
- [x] **As a team member, I want to use techNotes on desktop and mobile devices, so that I can access service information from the device available to me.**
